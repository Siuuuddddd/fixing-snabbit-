# Fixing Snabbit — Siddhesh
Open `index.html` directly, or open this folder in VS Code with Live Server.
For a local server, run `npx serve . -l 3000` here and visit http://localhost:3000.
The site uses plain HTML, CSS, JavaScript, and relative asset paths; no build step is needed.
To deploy later, run `vercel` from this folder, choose Framework “Other”, and set Output directory to `.`.
The five public-post images are in `assets/people-saying/`; prototype screens are in `assets/prototype/`.
